# Visual Validation

The isolated harness is rendered at desktop and compact widths after JavaScript execution.

Expected visual characteristics:

- exactly one selected palace;
- exactly three related palace highlights;
- exactly three SVG paths;
- paths are nearly invisible near their shared source;
- paths remain behind the protected centre card;
- three tiny crimson arrowheads terminate at destination palace borders;
- no route receives a loud semantic color different from the others.
