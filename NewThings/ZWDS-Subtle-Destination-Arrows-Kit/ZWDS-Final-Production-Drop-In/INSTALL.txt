ZWDS Final Production Drop-In — Installation Instructions
==========================================================

1. Back up the existing production files.
   The original-backup/ folder in this package contains copies of the
   files as they were before this patch.

2. Copy zwds.html into the site root (overwriting the existing file).

3. Copy the contents of assets/ into the existing assets/ folder.
   Approve overwrite for all files.

4. Hard-refresh with Ctrl+F5.

5. No npm install or build step is required.
   This remains a static HTML/CSS/JavaScript application.
